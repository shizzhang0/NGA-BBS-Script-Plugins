## ✨ 概述

增强本体的Excel模式，让更多页面伪装为表格

### 📋 版面：显示版头与子版面

本体开启Excel模式后，版头、版规与子版面入口会被全部隐藏

本插件在Excel模式下重新显示它们，并伪装为表格单元格，与帖子列表融为一体

- **版头**：显示为一个合并单元格，版主编写的表格改为Excel网格线，链接与文字统一为表格文字颜色，图片按比例缩小，隐藏链接后的“T”快速浏览按钮
- **子版面**：每个子版面显示为一个单元格，包含名称、描述与“显示/不显示此版面主题”勾选框，单元格与表头的列对齐，名称过长时自动合并更多列，一行放不下时自动换行
- 左侧行号列与帖子列表对齐，支持腾讯文档、WPS、Office 三种Excel主题

### 🏠 首页：伪装为表格

本体的Excel模式只在版面与帖子页生效，打开首页会直接显示原版页面；手动切换为Excel模式后，首页的版面入口又会被全部隐藏，只剩下轮播大图与广告

本插件让首页也进入Excel模式，并将整个首页排成一张表格

- **分类**：每个分类名(如网事杂谈、IT软硬件)占一整行，加粗显示
- **轮播**：去掉图片，每条轮播显示为一个超链接样式的单元格
- **版面**：每个版面显示为一个单元格，包含名称与描述，名称过长时自动合并更多列；“显示更多>>”可正常展开
- 左侧显示连续的行号，空白单元格也显示网格线，单元格与表头的列对齐
- 隐藏首页广告、版面图标与背景色

### 📝 发帖页：伪装为表格

本体的Excel模式只在版面与帖子页生效，打开发帖、回复、编辑页面时会直接显示原版的米黄色页面

本插件让发帖页也进入Excel模式，并将发帖表单排成表格

- 标题、BBCode按钮、格式按钮、选项、正文、附件各占一行，左侧显示行号，表单铺满整个表格宽度
- 深棕色的BBCode按钮与米黄色的按钮改为白底细边框，输入框与正文框改为白底
- 隐藏“发布/编辑”标题与深棕色的表头

### 👤 用户中心与短消息：伪装为表格

本体的Excel模式不处理用户中心(用户资料页)与短消息页面，打开时会直接显示原版的米黄色页面

本插件让这两个页面也进入Excel模式

- **用户中心**：基础信息、头像、签名、声望、物品/道具、发布的帖子等每个分类的标题与内容各占一行，标题加粗；按钮改为白底细边框，签名框、头像与物品框改为网格线边框
- **短消息**：收件箱的每条消息占一行，发件人、标题、时间之间显示网格线；读信页的每条回复、上下导航各占一行；写新消息的收件人、标题、内容各占一行

### 📄 提示页与版面权限页：伪装为表格

“找不到主题”、“你没有登录”等提示页，以及版面的“权限/版主”页面，都是没有NGA页面框架的纯文字页面

本插件让它们也进入Excel模式，并将每行文字拆分为一行表格

- **提示页**：提示信息(加粗)、后退、返回首页、页面地址各占一行
- **版面权限页**：页面标题与“满足以下条件可以访问”等小标题加粗，每个条件、每位版主各占一行

### 🔢 顶部分页栏：重新显示

本体的Excel模式会隐藏版面与帖子页顶部的分页栏，页码与精华区、收藏版面、发表新帖等按钮只能滚动到列表底部才能使用

本插件在Excel模式下重新显示顶部的分页栏，样式与底部的分页栏一致，伪装为一行表格，左侧行号显示“#”

- 本体开启**自动翻页**时，帖子页的收藏、发表回复按钮已固定在右上角，顶部不再重复显示；只有一页的帖子没有页码，整行隐藏

### 🧹 收藏与回复列表：细节优化

- **收藏的主题**：收藏夹切换栏的“默认”、“修改”按钮由彩色改为白底细边框；每行行号上的批量操作勾选框只在鼠标悬停该行或已勾选时显示，不再压住行号
- **我的回复**：每条回复内容上方的棕色分隔线改为网格线颜色

### 💬 弹框：改为白色样式

NGA的弹框(开始菜单、回复、评分等)为米黄底色、深棕色边框，开始菜单底部还有一条深棕色的大字用户名，在Excel界面中显得突兀

本插件在Excel模式下将弹框改为类似Excel菜单的白色浮层

- 白色背景、浅灰色细边框与淡阴影，边框颜色跟随当前Excel主题的网格线
- 开始菜单的分栏线与选中项改为灰色
- 底部的用户名改为一行浅灰色的状态栏，显示头衔、用户名与UID
- 只修改弹框的外框与背景，弹框内的回复框、按钮等保持原样；同时开启本体的暗色模式或护眼模式时不修改

## 🚀 使用方式

👉[点击安装](https://greasyfork.org/zh-CN/scripts/601193)，安装即可，默认无需配置

- **版面**：是否显示跟随本体的设置，在[NGA优化摸鱼体验]**设置面板**中关闭**隐藏版头/版规/子版入口**后，Excel模式下才会显示
- **首页**：在本体中开启**Excel模式**后，打开首页即自动进入Excel模式，仍可使用本体的快捷键切换回普通模式；不需要时可在插件配置中关闭
- **发帖页、用户中心、短消息、提示页、版面权限页**：在本体中开启**Excel模式**后，打开这些页面即自动进入Excel模式，仍可使用本体的快捷键切换回普通模式；不需要时可在插件配置中分别关闭
- **顶部分页栏、收藏与回复列表**：Excel模式下自动生效，不需要时可在插件配置中关闭
- **弹框**：Excel模式下自动生效，不需要时可在插件配置中关闭

## ⚙️ 配置项

在[NGA优化摸鱼体验]**设置面板** -> **插件管理** 中配置，修改后刷新页面生效

| 配置项 | 默认值 | 说明 |
| ---- | ---- | ---- |
| 首页显示为Excel表格 | 开启 | 关闭后首页保持本体原有的行为，不影响版面的版头与子版面显示 |
| 弹框使用白色样式 | 开启 | 关闭后Excel模式下的弹框保持NGA原有的米黄色样式 |
| 发帖页显示为Excel表格 | 开启 | 关闭后发帖、回复、编辑页保持本体原有的行为 |
| 用户中心显示为Excel表格 | 开启 | 关闭后用户中心保持本体原有的行为 |
| 短消息显示为Excel表格 | 开启 | 关闭后短消息页面保持本体原有的行为 |
| 提示页显示为Excel表格 | 开启 | 关闭后提示页保持本体原有的行为 |
| 版面权限页显示为Excel表格 | 开启 | 关闭后版面权限页保持原样 |
| 收藏与回复列表细节优化 | 开启 | 关闭后收藏列表与“我的回复”保持本体原有的样式 |
| 显示顶部分页栏 | 开启 | 关闭后Excel模式下顶部的分页栏保持本体的隐藏 |

## 📌 注意事项

- 如果NGA将版头折叠为“点击显示隐藏的置顶内容”，插件会自动展开，效果等同于点击该按钮，不会改变NGA的显示偏好
- 版头、子版面、首页的链接与勾选框均为NGA原生元素，功能不受影响
- 提示页与版面权限页的文字会被拆分到单独的行元素中，切换回普通模式后仍按行显示，与原页面的换行效果一致
- 在页面上开启或关闭**隐藏版头/版规/子版入口**后立即生效，无需刷新页面

## 🐛 已知问题

- 版面页出现横向滚动条并左右滚动时，行号列不会跟随移动
- 版头的排版由各版面的版主自由编写，个别版面的版头在表格样式下可能显示不够整齐
